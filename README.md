# Cruzeiro — Releases

Este repositório existe **apenas para distribuir os instaladores** do
Cruzeiro Desktop. Ele é público porque precisa ser: o app instalado busca
as atualizações aqui sem nenhuma credencial, e embutir um token num app
distribuído seria um problema maior que o que resolveria.

**O código-fonte não fica aqui.** Ele vive em um repositório privado.

## Downloads

Os instaladores de cada versão estão em
[Releases](../../releases) — Windows (`.exe`) e macOS (`.zip`).

---

*Até setembro de 2026 este repositório também recebia o código-fonte, por
um efeito não intencional do script de publicação. O conteúdo do branch foi
substituído por este aviso; as releases e seus arquivos seguem intactos.*
