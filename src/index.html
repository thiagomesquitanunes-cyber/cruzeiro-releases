📁 Pasta de dados

Escolha onde o Cruzeiro guarda os dados. Use uma pasta do Dropbox ou OneDrive para sincronizar entre computadores.
Pasta atual: Pasta padrão do sistema
💡 Após mudar a pasta, o arquivo de dados atual é copiado automaticamente para o novo local. Reinicie o app para garantir que tudo está sincronizado.

📦 Pasta de backup

Por padrão, os backups automáticos ficam numa subpasta dentro da própria pasta de dados. Recomendamos escolher uma pasta diferente (de preferência em outra unidade ou serviço de nuvem) — assim, se algo acontecer com o local dos dados, o backup não é afetado junto.
Pasta atual: Mesma pasta dos dados (subpasta "backups")

🔐 Senha de acesso

Defina uma senha para proteger o Cruzeiro. Ela será solicitada toda vez que o app for aberto.
🔐 Como funciona a segurança:
Ao definir uma senha, o banco de dados é criptografado com AES-256-GCM. Um código de recuperação é enviado ao seu email — sem ele, não é possível redefinir a senha. Um backup local de emergência também é salvo automaticamente.

👥 Usuários

Permite que mais de uma pessoa use o Cruzeiro neste computador, cada uma com seus próprios dados (extratos, ativos, senha) separados.
💡 Mais de um usuário cadastrado — ao reiniciar o app, uma tela vai pedir pra escolher quem está entrando.

🤖 Assistente IA

Ative a entrada de lançamentos por linguagem natural (texto) e os insights, usando a sua própria chave de IA. A entrada por voz está disponível no app móvel. A chave fica salva apenas neste computador.
